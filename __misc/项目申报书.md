## 项目简介

moonaprs 是一个用 MoonBit 从零实现的 APRS（Automatic Packet Reporting System）与
AX.25 协议栈，面向业余无线电爱好者、APRS-IS 网关开发者、气象/遥测数据采集者，以及
需要在 MoonBit 中处理分组无线电帧与地理数据的应用。

APRS 是全球业余无线电社区广泛使用的实时报文系统：电台通过 1200 bps 的 AX.25 分组
网络广播位置、天气、遥测与短消息，互联网侧则由 APRS-IS 骨干汇聚转发。moonaprs 覆盖
从比特级帧编码到语义解析、航迹聚合与地图渲染的完整链路，并同时提供命令行工具和浏览器
演示。

MoonBit 生态目前没有任何 APRS 或 AX.25 相关包（`moon search aprs`、`moon search
ax25` 均无结果），本项目填补这一空白。

## 核心功能范围

- **AX.25 帧层**：呼号与 SSID 规范化、地址字段编解码（6 字符左移、C/H 位、扩展位）、
  UI 帧（control `0x03`、PID `0xF0`）、CRC-16/X.25 帧校验序列。
- **HDLC 与 KISS**：连续 5 个 `1` 后插入 `0` 的位填充与去填充；KISS 分帧、`0xDB`
  转义、跨数据块的增量流解码。
- **TNC2 monitor 格式**：`SRC>DST,PATH:info` 的解析与渲染，路径已转发标记。
- **APRS-IS 支持**：passcode 算法（`N0CALL → 13023` 等回归向量）、登录行、只读模式、
  范围/矩形/前缀/好友/类型过滤器构造、会话状态机（keepalive、`#` 注释、登录确认）、
  重复包窗口（忽略路径按报文签名去重）。
- **报文语义解析**：
  - 非压缩位置（`ddmm.hhN/sssmm.hhW`）与位置歧义；
  - 压缩位置（base-91，规范示例 `!/5L!!<*e7>7P[` → 49.5°N 72.75°W）；
  - Mic-E 压缩位置（纬度编码在 AX.25 目的地址，规范示例 `DG0P2R` → 36°00.22′N
    86°43.29′W，含速度/航向、符号与状态文本）；
  - 带时间戳位置（`DDHHMMz`）、气象报文、位置附带气象（`_` 符号与 `DDD/SSS` 前缀）；
  - 遥测（`T#`）、消息与 ACK、状态、对象、条目、查询、第三方报文；
  - 公告与 NWS 分类（`BLN0`-`BLN9`、5 字符主题）；
  - 时间戳解析（`z`/`/`/`h`/`MMDDHHMM`）、主备符号表与 overlay、位置报文构造。
- **航迹处理**：按呼号/对象/条目聚合、20 米内重复信标去重、大圆距离、初始方位、
  罗盘方位、Maidenhead 网格、分段速度/航向、Douglas-Peucker 航迹简化、GPX 1.1 与
  GeoJSON 导出。
- **地图渲染**：Web Mercator 投影、SVG 航迹折线、按符号绘制三角/方形/菱形标记、
  公里比例尺、起终点标记、呼号标注、经纬网。
- **工具链**：CLI 子命令 `decode` / `decode-file` / `encode` / `passcode` / `login` /
  `kiss` / `track` / `svg` / `gpx` / `geojson` / `is-feed` / `symbols`；MoonBit → JS
  浏览器演示（粘贴报文即时解码并绘图，可下载 GPX / GeoJSON）。

## 现有基础

- 已按 MoonBit 包结构实现 `lib/ax25`、`lib/aprs`、`lib/track`、`lib/svg` 四个核心包，
  以及 `cmd/main` 命令行与 `web` 浏览器演示，并配置三端（native / Wasm / JS）
  可编译的 CI 检查。
- AX.25 编码已用公开规范校验：地址字段左移编码、SSID/扩展位、CRC-16/X.25
  标准校验值 `0x906E`、HDLC 填充位数、KISS 转义与流式解码。
- APRS 解析已覆盖压缩/非压缩位置、歧义、时间戳、气象、遥测、消息/ACK、对象、条目、
  状态、查询、公告分类，并用规范示例与真实报文语料做回归。
- APRS-IS 侧已实现 passcode、登录串、过滤器、会话状态机与重复包窗口。
- 航迹模块已实现去重、距离/方位、速度/航向、Douglas-Peucker 简化，以及 GPX 与
  GeoJSON 导出；SVG 渲染支持符号标记与比例尺，可在浏览器与 CLI 中直接查看。
- 已提供 95 个单元测试，`moon test --target wasm` 全绿；CLI 与浏览器演示均已实测。

## 本次计划新增

## 预期目标与技术路线

以 MoonBit 作为唯一主实现语言，保持核心库无平台依赖，原生 / Wasm / JS 后端均可编译。
技术路线：

1. 先实现可回归验证的比特层（地址字段、CRC、位填充、KISS），以公开规范和已知字节为准；
2. 在比特层之上实现 TNC2 与 APRS 报文语义，按信息字段首字符分派，逐类覆盖；
3. 以位置报文为输入构建航迹层，完成去重、几何计算与简化；
4. 将航迹投影到 Web Mercator 并输出 SVG，CLI 与浏览器演示共用同一套库；
5. 以单元测试与真实报文语料保证正确性，最后补齐 APRS-IS 客户端。

目标是把项目做成边界清晰、可测试、可长期维护的 MoonBit 协议与地理数据处理基础库。
